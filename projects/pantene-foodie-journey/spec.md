# Product Spec

## 1. 產品目標

建立一個屬於 Pantene 嘅手機系統，主要做三件事：

- 幫你快速決定食咩
- 幫你隨心推介餐廳
- 俾朋友可以安全留言互動

## 2. 使用者

- 主要使用者：你
- 次要使用者：太太 / 朋友
- 訪客：被分享連結嘅朋友

## 3. 核心功能

### A. 今日食咩

- 今晚想食咩快捷入口
- 推薦清單
- 收藏清單
- 最近去過
- 按條件篩選：
  - 地區
  - 價錢
  - 類型
  - 情緒 / 心情
  - 場景，例如打卡、輕食、宵夜、約會

### B. Pantene 隨心推介

- 隨機推介六間餐廳
- 可一按「再推介」重洗清單
- 可按地區、價錢、類型、心情瀏覽

### C. 朋友留言

- 每個餐廳可開留言
- 可控制公開 / 朋友可見 / 私密
- 留言要簡單直接

## 4. MVP 頁面

- Home Dashboard
- 食咩推薦
- 餐廳推薦詳情
- 留言頁

## 5. 資料結構建議

- User
- Place
- Comment
- Favorite
- Tag

## 6. 產品守則

- 一定手機優先
- 一定簡單
- 一定快
- 一定易分享
- 文字唔好太多層級

1. 做 wireframe
2. 起 mobile UI prototype
3. 加資料儲存
4. 加分享 / 留言權限
