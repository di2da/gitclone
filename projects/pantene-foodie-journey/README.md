# Pantene's Foodie Journey

獨立項目定位：

- 手機優先
- 俾你平日諗唔到食咩時快速睇靈感
- 俾朋友睇同留言
- 集中保存食飯推介

## 核心用途

1. 食咩決策
   - 快速睇「今日食咩」
   - 收藏想試餐廳
   - 按地區、價錢、心情、口味篩選

2. Pantene 隨心推介
   - 隨機推介六間餐廳
   - 可以一按再推介
   - 按條件睇餐廳

3. 分享同留言
   - 可分享俾朋友睇
   - 朋友可以留言
   - 可選擇每間餐廳嘅公開程度

## MVP 建議

- Home
- 今日食咩
- Pantene 隨心推介
- 留言牆

## 建議模式

- Web App / PWA
- iPhone / Android 手機瀏覽器可直接用
- 可加「加入主畫面」

## 風格方向

- 溫暖、輕鬆、可愛，但唔幼稚
- 主要色調可用奶油白、蜜桃橙、薄荷綠
- 介面要大字、大按鈕、少層級
